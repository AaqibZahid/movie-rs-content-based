# Movie Recommendation System

## What it does

* You select a movie
* The app suggests similar movies
* Recommendations are based on cosine similarity

![Movie Recommender Screenshot](assets/screenshot.png)

---

## 🛠️ Built with

* Python
* Pandas, NumPy
* Scikit-learn
* Streamlit

---

## How to Run Locally

1. **Clone the repo**

```bash
git clone https://github.com/AaqibZahid/movie-rs-content-based
cd movie-recommendation-system
```

2. **Install dependencies**
   *(run this in the same folder where `requirements.txt` is)*

```bash
pip install -r requirements.txt
```

3. **Run the app**

```bash
streamlit run app.py
```

The app should open in your browser automatically.
